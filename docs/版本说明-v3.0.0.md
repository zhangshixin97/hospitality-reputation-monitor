# 旅声 v3.0.0

面向酒店、民宿和景区的离线舆情工作台，由张世鑫AI发起，采用MIT许可证。

本版新增可全屏查看的监控大盘，放大主标题和工作区文字，沿用蓝点与品牌蓝。支持手工登记、中文CSV导入预览、回复模板、真实处置记录和整改台账。虚构演示空间可独立体验完整流程。

改善了重复导入、未知时间、日期精度、来源状态合并、来源变更后重新核验、人工风险等级排序，以及JSON工作空间的备份恢复。

公开仓库只包含通用代码、使用文档和虚构示例。实际业务数据、客户身份、非公开项目标识、登录状态和本地备份不随代码发布。

当前未内置持续采集、自动群告警或多人同步。OTA、社交平台及地图数据需要授权整理后导入。本地规则与模板不调用大模型，也不会自动联系客人。

使用方法：打开 `index.html`，从“体验示例”开始；处理真实数据前退出演示。门店流程和开发贡献说明见README。
