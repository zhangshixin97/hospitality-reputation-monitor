# 张世鑫AI · 旅声视觉

本项目参考张世鑫个人网站与品牌VI，延续名字、蓝点、品牌蓝和清晰的文字层级。工作台强调可读、可核验和反复使用。

| 用途       | 规则                                                     |
| ---------- | -------------------------------------------------------- |
| 名字       | 张世鑫AI，AI大写；工具名旅声                             |
| 主标题     | 酒旅舆情监控与预警系统；桌面32px、手机27px               |
| 品牌蓝     | `#3B5BFD`，用于蓝点、链接、选中态和明确命令              |
| 主文字     | `#111318`                                                |
| 次要文字   | `#6B7280`                                                |
| 背景       | `#F6F7F9` 与白色                                         |
| 语义色     | 红色风险、橙色待关注、绿色正面与已完成；与品牌色各司其职 |
| 中文       | 优先本机MiSans，回退至系统中文字体                       |
| 英文与数字 | 本地JetBrains Mono，附带原许可证                         |
| 正文       | 桌面16px、手机15px；列表正文14px，辅助信息保留清晰对比   |
